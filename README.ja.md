# Windy

[English](README.md)

Windy は、キーボード操作を中心にした左右2ペイン型のデスクトップファイルマネージャーです。

2つのファイルペイン、内蔵ターミナル、アーカイブ閲覧、ローカル検索、ファイルプレビュー、基本的なSFTP操作を、Tauri製のデスクトップアプリとしてまとめています。

> Windy は現在ベータ版です。重要なファイルを扱う前にバックアップを取り、削除や移動などの破壊的な操作は、まず重要でないデータで試してください。

## 主な機能

- キーボード操作を中心にした左右2ペインのファイル閲覧
- ローカルファイルのコピー、移動、リネーム、削除、新規フォルダ、新規ファイル作成
- ローカルファイルはOSのゴミ箱を使った削除と、明示的な完全削除に対応
- 内蔵テキストビューア、画像ビューア
- ZIP、TAR、TAR.GZ、TGZ のアーカイブ閲覧と展開
- クイックフィルタと詳細検索結果ペイン
- ローカルディレクトリの比較
- 安全な一部操作のUndo/Redo
- ファイル選択と連携する下部ターミナル
- パスコピーと外部コマンドテンプレート
- SFTP接続プロファイルとローカル/SFTP間の基本転送
- macOS、Windows、Linuxを想定したコードベース

## ベータ版について

このリポジトリは Windy の公開ベータ版スナップショットです。

現時点の注意点:

- UIはキーボード操作に最適化されています。マウス操作中心のファイル操作は意図的に対象外です。
- 内蔵SFTP機能は、日常的な軽量転送を想定しています。大容量・長時間・再開可能性・厳密な整合性確認が必要な転送では、ターミナルから `rsync`、`scp`、`sftp`、`rclone` などを使ってください。
- アーカイブやリモートソースの一部操作は、読み取り専用または制限付きです。
- macOSビルドは、リリースノートで明記されていない限り、ad-hoc署名または未署名の場合があります。

詳しくは [ベータ版ノート](docs/BETA_NOTES.md) を参照してください。

## ダウンロード

ベータビルドがある場合は、このリポジトリの Releases ページから公開します。

まだ利用中のOS向けリリースアセットがない場合は、以下の手順でソースからビルドできます。

## ソースからビルド

必要なもの:

- Node.js 22 以降
- pnpm
- Rust stable toolchain
- Tauri 2 の各OS向け前提パッケージ

依存関係をインストールして確認します。

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
cargo test --manifest-path src-tauri/Cargo.toml
```

開発モードで起動します。

```sh
pnpm tauri dev
```

アプリをビルドします。

```sh
pnpm tauri build
```

開発者向けの補足は [Development](docs/DEVELOPMENT.md) を参照してください。

## 基本操作

Windy はキーボード操作を中心に設計されています。

| キー | 操作 |
| --- | --- |
| `up` / `down` または `k` / `j` | カーソル移動 |
| `left` / `right` または `h` / `l` | ペイン移動または親ディレクトリへ移動 |
| `enter` | ディレクトリまたはファイルを開く |
| `space` | フォーカス項目のマーク切り替え |
| `c` | 選択項目を反対ペインへコピー |
| `m` | 選択項目を反対ペインへ移動 |
| `r` | リネーム |
| `d` / `delete` | 削除。ローカルではゴミ箱を使用 |
| `shift+delete` | 完全削除 |
| `n d` | フォルダ作成 |
| `n f` | 空ファイル作成 |
| `ctrl+n` | Location Managerを開く |
| `/` | クイックフィルタ |
| `f` | 詳細検索 |
| `tab` | ターミナルへフォーカス移動 |
| `?` | キーヘルプ表示 |

詳しくは [ユーザーガイド](docs/USER_GUIDE.ja.md) を参照してください。
